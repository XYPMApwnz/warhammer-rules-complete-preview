Attack Sequence

Resolve every attack through four ordered steps. If an attack fails or inflicts damage, its sequence ends.

Source PDF ↗Next: Movement Phase →
05.01

Hit Rolls

PAGE 18

Roll one D6 for every attack dice and apply the first matching result:

  • An unmodified 1 fails.
  • An unmodified 6 is a .
  • A result equal to or greater than the attack’s BS or WS is a hit.
  • Any other result fails.
05.02

Wound Rolls

PAGE 18

Roll one D6 for every hit. An unmodified 1 fails and an unmodified 6 is a . Otherwise compare Strength with Toughness:

S ≥ 2 × T2+
S > T3+
S = T4+
S < T5+
2 × S ≤ T6+
05.03

Save Rolls

PAGE 19
  1. Create groups: one group for each CHARACTER; group other models sharing W, Sv and InSv.
  2. Declare allocation order: wounded non-CHARACTER models first; CHARACTER groups cannot precede non-CHARACTER groups; wounded CHARACTER groups precede unwounded CHARACTER groups.
  3. Roll saves: the opposing player rolls one D6 for each attack that wounded the target.
05.04

Inflict Damage

PAGE 19
  1. Select a model in the current allocation group, choosing a wounded model where possible.
  2. Check the save: an unmodified 1 inflicts damage. An applicable InSv result or a modified save meeting Sv causes the attack to fail. Any other result inflicts damage.
  3. Resolve damage: the model loses wounds equal to the attack’s D. At 0 wounds or fewer, it is destroyed.

Work from the lowest save results to the highest. If every model in the target unit is destroyed, excess attacks are lost.
