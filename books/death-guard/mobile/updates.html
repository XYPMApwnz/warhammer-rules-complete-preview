Faction Pack Rules Updates

Nurgle’s Gift - Contagion Range: Contagion Range cannot be greater than 12" after modifiers.

Nurgle’s Gift - Skullsquirm Blight: each time a model in this unit makes a melee attack, subtract 1 from the Hit roll.

Tallyband Summoners - Beckoning Blight: DEATH GUARD model only. Each time a PLAGUE LEGIONS unit from your army is set up on the battlefield using the Deep Strike ability, if it is set up wholly within 12" of the bearer, it can be set up anywhere that is more than 6" horizontally away from all enemy models, instead of more than 8".

Add FRAME to Chaos Land Raider, Chaos Predator Annihilator, Chaos Predator Destructor, Chaos Rhino, Miasmic Malignifier and Plagueburst Crawler.

Typhus - Eater Plague: In your Shooting phase, you can select one enemy unit within 18" of and visible to this PSYKER (excluding units with the Lone Operative ability that are not part of an Attached unit and are not within 12" of this PSYKER) and roll one D6: on a 1, this PSYKER’s unit suffers D3 mortal wounds; on a 2-5, that enemy unit suffers D6 mortal wounds; on a 6, that enemy unit suffers D3+3 mortal wounds.

Chaos Predator Destructor - Predator autocannon: Strength 9.

Deathshroud Terminators - Death Approaches: Each time this unit is set up on the battlefield using the Deep Strike ability, it can be set up anywhere on the battlefield that is more than 6" horizontally away from all Afflicted enemy units, and more than 8" horizontally away from all other enemy units.

FAQ: Plagueburst Crawler’s Spore-laced Shock Waves ability does not inflict mortal wounds every turn to units affected by the ability.
