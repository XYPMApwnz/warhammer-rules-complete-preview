Command Phase

Command Points, Battle-shock and Command phase rules.

Official GW PDF ↗← The Battle RoundMovement Phase →

1. Start of Command Phase

Official PDF · page 30

Rules that are triggered at the start of the Command phase are resolved now.

2. Gain Core CP

Digital 11E

Both players gain 1 Command Point (CP).

Command Points
Official GW update · Source ↗

Command Points are a valuable resource you can spend to use . The step ensures that both players gain 1CP each turn. While these are termed Core CP here, they are Command Points like any other. Other rules sometimes mention ‘Core CP’ when referring to these Command Points.

You can only generate a single extra CP per battle round.

3. Battle-shock Step

Digital 11E

The must now make one for each unit in their army that fulfils one or both of the following conditions:

  • That unit is currently battle-shocked.
  • That unit is at, or below, half-strength.

If a unit was battle-shocked at the start of this step and its battle-shock roll during this step succeeds, it is no longer battle-shocked.

See also

Multiple Battle-shock Rolls
Digital 11E

In the , unless otherwise stated, no more than one battle-shock roll can be made by each unit. If for any reason a unit must make a battle-shock roll in this step before one it is required to make for being battle-shocked or at or below half-strength, that unit does not also have to make the battle-shock roll for being battle-shocked or at or below half-strength.

4. Command Abilities

Official PDF · page 30

Rules that are triggered in the Command phase (excluding those that are triggered at the start or end of this phase, when gaining Core CP, or by ) are resolved now.

5. End of Command Phase

Digital 11E

Rules that are triggered at the end of the Command phase are resolved now, in the following order:

  • First resolve rules triggered at this point other than mission rules.
  • Both players then consult their mission; if one or both players have achieved any aspects of their mission that are triggered at this point, resolve them now.

EXAMPLES

This unit has a starting strength of 3 so is not at or below half-strength, but it is currently battle-shocked, so a battle-shock roll must be made for it. If that roll succeeds, the unit will no longer be battle-shocked.

This unit has a starting strength of 10. It has five models remaining, so it is at half-strength and a battle-shock roll must be made for it.

This unit has a starting strength of 5. It has two models remaining, so it is below half-strength and a battle-shock roll must be made for it.

This VEHICLE has a starting strength of 1 and a W characteristic of 11. It has 3 wounds remaining, so it is below half-strength and a battle-shock roll must be made for it.
