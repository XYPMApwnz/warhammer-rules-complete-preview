Command Phase

Command Points, Battle-shock and Command phase rules.

Official GW PDF ↗← The Battle RoundMovement Phase →

1. Start of Command Phase

rule

Rules that are triggered at the start of the are resolved now.

2. Gain Core CP

rule

Both players gain 1 Command Point (CP).

See also

Command Points

Command Points are a valuable resource you can spend to use . The step ensures that both players gain 1CP each turn. While these are termed Core CP here, they are Command Points like any other. Other rules sometimes mention ‘Core CP’ when referring to these Command Points.

If a unit was battle-shocked at the start of this step and its battle-shock roll during this step succeeds, it is no longer battle-shocked.

Multiple Battle-shock Rolls

In the , unless otherwise stated, no more than one can be made by each unit. If for any reason a unit must make a battle-shock roll in this step before one it is required to make for being or at or , that unit does not also have to make the battle-shock roll for being battle-shocked or at or below half-strength.

4. Command Abilities

rule

Rules that are triggered in the (excluding those that are triggered at the start or end of this phase, when gaining Core CP, or by ) are resolved now.

5. End of Command Phase

rule

Rules that are triggered at the end of the are resolved now, in the following order:

  • First resolve rules triggered at this point other than mission rules.
  • Both players then consult their mission; if one or both players have achieved any aspects of their mission that are triggered at this point, resolve them now.
