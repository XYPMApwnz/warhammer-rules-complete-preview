Using Stratagems

Digital 11E

During the battle, both players can use stratagems. Each stratagem states:

  • How many CP it costs to use.
  • WHEN: When it can be used.
  • TARGET: Which units it can target.
  • EFFECT: What the effects of using that stratagem are.
  • RESTRICTIONS: Any additional restrictions that apply.

Each player can use the same stratagem multiple times during the battle, but the following restrictions apply:

  • Each player cannot use the same stratagem more than once in the same phase.
  • Unless otherwise stated, each player cannot target the same unit with more than one stratagem in the same phase.

Each time you use a stratagem, resolve the following sequence:

  • as described in that stratagem.
  • Reduce your CP total by the CP cost listed in that stratagem. If that stratagem contains a section that carries an additional CP cost (e.g. +1CP), you can only use that additional section if you increase the CP cost of that stratagem by the amount shown. If you do not have enough CP remaining, you cannot use that stratagem.
  • Resolve the effects of that stratagem.

Some stratagems feature optional conditions that carry on additional CP cost. This can depend on the effect you select (see stratagem for example) or other variables such os the keywords of the unit being targeted.

Accepted Wahapedia FAQ · 2026-09-25 · Source ↗

After using an ability that increases the CP cost of a stratagem, must my opponent continue to use the selected stratagem at the increased cost if they have the necessary CP available?

Yes.

Accepted Wahapedia FAQ · 2026-09-25 · Source ↗

After using an ability that increases the CP cost of a stratagem, if my opponent does not have the necessary CP available for the selected stratagem, what happens?

No CP are spent and that stratagem's effects are not resolved (but that stratagem still counts as having been used this phase).

Related rules
Accepted Wahapedia FAQ · 2026-09-25 · Source ↗

If a stratagem contains a section that carries an additional CP cost (such as the Into the Fray option of ), is that additional cost considered to be a modifier?

No, a stratagem that costs 1CP and is making use of an optional +1CP section has an original cost of 2CP.

Modifying CP Cost
Digital 11E

Some rules modify the cost of using certain stratagems. In such cases, the following points apply:

  • The CP cost of a stratagem use can never be modified below 0CP.
  • If a rule modifies the CP cost of a stratagem when you use it, but does not specify a duration for that modifier, that modifier only applies to that usage of that stratagem.
Affected By A Stratagem
Digital 11E

If a unit is selected as the target of a stratagem, it is said to be affected by that stratagem.

Stratagem Definitions
Digital 11E
  • Your Opponent’s Stratagems: stratagems that your opponent uses are sometimes referred to as your opponent’s stratagems.
  • Your Stratagems: stratagems that you use are sometimes referred to as your stratagems.
  • Your Unit (in Stratagems): The term ‘your unit(s)’ in the Effect section of stratagems always relates to the unit(s) selected in the Target section of that stratagem, and never refers to any other units from your army.

COMMAND RE-ROLL

Digital 11E

A great commander can bend even the vagaries of fate and fortune to their will, the better to ensure victory.

WHEN

Any phase, just after you make one of the following rolls for a friendly unit or model:

  • Advance roll
  • Charge roll
  • Damage roll
  • Hazard roll
  • Save roll
  • A roll to determine the number of attacks generated with a weapon.
TARGET

That unit or model.

EFFECT

You re-roll that roll. If you are rolling more than one dice together, select one of those dice to re-roll (excluding charge rolls, which you must re-roll in full).

Universal Rules Updates

Current official updates to rules with a broader scope than individual Faction Packs. GW source ↗

Modifying a Stratagem's CP Cost

Official GW update

If a rule lets you target a friendly unit with an unnamed Stratagem for 0CP, it instead reduces the CP cost of that use by 1CP.

Stratagems That Can Be Used More Than Once per Phase or Turn

Official GW update

Parts of a rule permitting a Stratagem to be used after another unit was targeted with it in the same phase apply only if that rule explicitly names the Stratagem. The same requirement applies to bypassing a Stratagem's one-use-per-player limit per turn, battle round or battle.

Stratagems That Prevent Units from Being Targeted

Official GW update

If a Stratagem prevents ranged attacks against its target unless the attacking model is within 12 inches, that distance becomes 18 inches for either form of this restriction specified in the official update.

Stratagems That Add New Units to Your Army

Official GW update

A Stratagem that adds a new unit identical to one of your destroyed units gains a once-per-battle use restriction.

Move Types for Disembarking Units

Official GW update

If a rule allows a unit to declare a charge after disembarking from a TRANSPORT that made a normal move that turn, the unit makes an assault disembark move instead of a disembark move. If a rule allows a unit to disembark from a TRANSPORT that made an advance move that turn, the unit makes a shock disembark move instead of a disembark move.
