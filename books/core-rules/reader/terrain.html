Terrain

Moving over terrain, visibility, cover and terrain features.

11E reference ↗← Fight PhaseObjectives →

rule

Before the battle, place a selection of terrain features on the battlefield using one or more of the following methods:

  • Place a well-defined boundary (such as a base or mat) in each location want to furnish with terrain, then place one or more terrain features that boundary.
  • Place one terrain feature directly on the battlefield.
  • Place two or more terrain features directly on the battlefield in such a way that together they define the boundary of an area.

In each case, the area of the battlefield occupied by that boundary or terrain feature is known as a terrain area. A mission’s map may define the location and dimensions of each terrain area. Otherwise, players must agree on this before the battle.

rule

Each terrain feature belongs to a terrain category, which can affect the and of models. Below are some examples of which types of terrain features fall under each category.

rule

Models can move through different categories of terrain feature as follows:

  • /: All models can move horizontally and vertically through and terrain features.
  • :
  • /BEASTS// models can move horizontally through terrain features.
  • /BEASTS/ models can move vertically through terrain features.
  • Other models can move horizontally through terrain features provided that all sections of that terrain feature that the moving model’s base would move through are 2" or less in height. Otherwise, the moving model must move vertically to ascend or descend such sections. They cannot move through ceilings and floors while doing so, and they cannot end that move on any surface of that terrain feature that is not on ground level (see below).

See also

If a terrain feature has the rule (), as terrain features do, a model cannot end a move such that any part of it is through any enclosed part of that terrain feature that is 3" or less from ground level – not even through small openings such as doors and windows. This ensures that protruding elements of models cannot be used to circumvent the restrictions of the rule.

Each time a ranged attack targets a unit, if every model in that unit meets one or more of the following conditions, that unit has the against that attack:

  • That model has the /BEASTS/ keyword and is a terrain area.
  • That model is not fully visible to the attacking model due to one or more intervening terrain features and/or one or more intervening terrain areas (see below).

Each time a ranged attack targets a unit that has the against it, worsen the BS characteristic of that attack by 1.
