# Retired V1 compatibility pipeline

The former snapshot-to-matrix compatibility pipeline was retired by the owner
on 2026-11-07. Its dedicated matrices, builders, importers, correction ledgers,
reports and tests are no longer current build or publication inputs. Git history
preserves the previous design and review evidence.

Unified V2 derives Related Rules from native Rule Contracts. The shared producer
and the native book producers own the compiled applicability results consumed by
the application; see [the repository map](codex/REPO_MAP.md) and the
[source/gameplay contract](PROJECT_SOURCE_OF_TRUTH.md). This retirement changes
neither gameplay facts nor the native applicability rules.

The retained Space Marines mixed-source snapshot, V1 related-rules producer and
points tools are outside this cleanup and remain subject to their existing
source and build contracts.
