## New player-facing help

The existing refusal remains: “The export header could not be recognized. Your current roster and saved roster were not changed.”

The explanatory text is:

> The supported plain New Recruit header starts with exactly three nonempty lines: list name and total points, faction, and Detachment(s). For example:

```text
Unnamed list (950 Points)
Death Guard
Contagion Engines and Paragons of Putrescence (2 Detachment Points)
```

> Newer exports may add a Force Disposition and an Incursion or Strike Force battle size after the Detachment line, in either order. Each optional line can appear only once. Five-line example:

```text
Unnamed list (760 Points)
Death Guard
Shamblerot Vectorium and Virulent Vectorium (5 Detachment Points)
Disruption
Strike Force (2,000 Points)
```

> Re-export the roster as text from New Recruit and try again. If the header is still different, send the original export as a sample to the site owner.
