# Product structure

The current product description and compatibility decision are maintained in [README](../README.md). Unified V2 is the sole user interface. The root opens `v2/app.html`; nine native Army Books, the existing Core iframe reader, Mega Glossary and the physical roster/Effective/Guide path share that application.

V1 readers, Roster Guides, separate mobile route files and V1 URL/roster/update compatibility are retired. This replaces the old compatibility obligations formerly described here. Existing V2 data ownership, physical scope, source attribution, independent certification and QA obligations remain in [PROJECT_SOURCE_OF_TRUTH](PROJECT_SOURCE_OF_TRUTH.md), [ARMY_BOOK_BLUEPRINT](ARMY_BOOK_BLUEPRINT.md) and the native contracts linked by README.
